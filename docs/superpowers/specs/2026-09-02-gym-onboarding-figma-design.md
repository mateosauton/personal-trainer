# Gym onboarding Figma flow

## Goal

Create a calm, practical mobile onboarding flow for Office Gym. It should help a new member set up a tailored training plan with minimal cognitive load and reflect the app's dark, high-contrast visual language.

## Experience

The flow uses one decision per screen, clear default choices, brief helper copy, and a fixed primary action. It contains eight 390 × 844 mobile frames:

1. Welcome — concise promise and Get started action.
2. Goal — strength, muscle, fitness, or fat loss.
3. Experience — new, comfortable, or experienced.
4. Weekly cadence — 2–6 days, defaulting to four.
5. Session length — 30, 45, 60, or 75 minutes, defaulting to 45.
6. Profile — optional name and photo, with an explicit skip option.
7. Considerations — multi-select training limitations and None.
8. Plan ready — summary of selections and View my plan action.

## Visual direction

Use the product's near-black background, dark elevated surfaces, white high-contrast typography, and electric-lime primary action color. Large display typography is reserved for the welcome and confirmation moments; selection screens use compact titles, quiet helper text, and spacious cards. Progress is always visible but understated.

## Figma structure

Create a single page containing the eight connected screens and a small local component area for primary buttons, option cards, chips, and the progress rail. The screens use auto-layout and reusable styles so they are straightforward to edit and hand off.

## Scope and checks

This work is a design artifact only. Review for legible contrast, consistent 8-point spacing, a reachable primary action on every decision screen, and clear selected/unselected states.
